# Statistical Data Analyzer

Модуль первичного статистического анализа числовых данных на чистом Python.

---

## Функциональность

Класс `Analyzer` принимает табличные данные в виде словаря колонок (`dict[str, list]`) и рассчитывает базовые метрики:

- **Меры центральной тенденции:**
  - `avg()` — среднее арифметическое.
  - `median()` — медиана.
  - `mode()` — мода (наиболее часто встречающееся значение).
- **Меры вариации и разброса:**
  - `min()`, `max()` — экстремумы выборки.
  - `std()` — генеральное стандартное отклонение ($\sigma$).
  - `quantile(p)` — квантиль порядка $p \in [0.0, 1.0]$ с непрерывной линейной интерполяцией.
- **Меры взаимосвязи:**
  - `covariance(target)` — ковариация всех числовых столбцов относительно целевого признака.
  - `correlation(target)` — линейная корреляция Пирсона ($r \in [-1, 1]$) относительно целевого признака.

## Запуск и использование

### 1. Требования
- Python 3.8+

### 2. Пример кода
```python
from analyzer import Analyzer

data = {
    'study_time_hours': [4.0, 6.3, 4.9, 2.6],
    'final_exam_score': [100.0, 100.0, 97.3, 83.8],
}

analyzer = Analyzer(data)

# Расчёт отдельных статистик
analyzer.avg()
analyzer.median()
analyzer.std()
analyzer.quantile(0.25)

# Анализ связи факторов с целевой переменной
analyzer.correlation('final_exam_score')
analyzer.covariance('final_exam_score')
